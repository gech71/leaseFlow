# **App Name**: LeaseFlow

## Core Features:

- Space Definition: Accept available space details: Building, Space ID/Name, Area, Floor, Utility Rate (100%), and Monthly Rental Price.
- Agreement Generation: Automatically generate rental agreements when a customer rents a space, including customer name, space details, and predefined terms using a tool.
- Bill Generation: Generate bills for rental and utility payments based on the agreement terms using a tool.
- Customer Portal: Provide an online portal for customers to view payment details and upcoming payments.
- Admin Dashboard: Provide tenant and payment overviews for property managers.

## Style Guidelines:

- Primary color: Moderate blue (#64B5F6) to evoke trust and reliability, without being a saturated or cliched blue.
- Background color: Very light blue (#F0F8FF) to provide a clean and professional backdrop.
- Accent color: Light purple (#B39DDB) to add a touch of sophistication and highlight key actions, contrasting in both brightness and saturation.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, 'Inter' (sans-serif) for body text.
- Use a clean, card-based layout for space listings and payment overviews.
- Use simple, clear icons to represent space types, utilities, and payment status.
- Subtle transitions and animations on dashboard elements to improve user experience.
